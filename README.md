Focus spent on the past is motion not taken. Today shapes tomorrow. Small steps, recorded, accumulate.

## Structure

- `log/` — append-only JSONL entries. One file per day or per significant event. Each line is a JSON object with full provenance.
- `milestones/` — recorded milestones with status and evidence links.
- `status/` — veteran-declared status updates (self-attested + metadata).
- This repository is the source of truth. Commits are the append-only mechanism. Do not rewrite history.

## Provenance requirements for every append

- Timestamp (ISO 8601, UTC preferred)
- Actor declaration (name, veteran status, contact method if offered, any other self-declared facts)
- Commit metadata (author, committer, SHA, parent)
- Any available technical metadata (user-agent, IP hash if captured by the interface, etc.)
- Explicit statement of what is being added or refined
